# Задачи
Написать свой модуль на основе phpdevorg.cprop  
Модуль должен добавлять для элементов инфоблока комплексное свойство  
Одним из типов комплексного свойства должен быть HTML редактор, как в модуле d2mg.ufhtml 

### Реализация в CIBlockPropertyCProp.php
**1. `<b>showHtmlEditor</b>` (строки 330-354):**
Отображает HTML-редактор, используя поле с именем `HTML_BITRIX[код_поля]` для ввода и сохранения данных. 

**2. `<b>checkHtmlInputs</b>` (строки 180-193):**
Проверяет массив $_POST, находит поля с именами, начинающимися на `HTML_BITRIX`, отрезает префикс и возвращает массив в формате `ключ → значение`. 

**3. `<b>ConvertToDB</b>` (строки 195-203):**
Перед сохранением вызывает `checkHtmlInputs()`, чтобы получить данные из HTML-редактора, и записывает их в `$arValue['VALUE'][код_поля]`.
